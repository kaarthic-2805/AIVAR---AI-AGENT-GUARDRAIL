# AIVAR---AI-AGENT-GUARDRAIL
EstateGuard AI is an advanced multi-agent real estate platform powered by LangGraph, MCP, and Groq. It enforces pre-execution action guardrails using declarative YAML policies to safely evaluate agent tool actions—such as database deletions, email dispatches, and file access—alongside supervisor routing, simulation testing, and HITL approvals.



### Current Deployment Stack
- FastAPI backend
- MCP integration
- Action Guardrail policies
- Docker containerization
- AWS EC2 deployment
- GitHub-based source management
